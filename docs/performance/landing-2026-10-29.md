# 首页性能优化（2026-10-29）

## 已完成

- `/zh`、`/en` 在构建时生成 HTML，由 Cloudflare Static Assets 直接提供，避免重复 SSR。
- 使用精确的 `_redirects` 映射，保留百度验证文件的 `.html` 地址，并规范首页的尾斜杠与 `.html` 地址。
- Node 自托管入口同样优先返回静态首页；HTML 要求重新验证，带内容哈希的资源长期缓存。
- 编辑器组件库、简历存储与目录同步、编辑器字体和样式、通知组件进入应用时才加载。
- 首页 GitHub 按钮不再加载动画运行库；计数延后请求、共享结果并限制等待时间。
- 首页截图使用带内容哈希的 WebP，并按屏幕尺寸选择 640、1280、2560 像素版本；主视觉增加 768 像素版本。
- 首页截图延迟加载，主视觉保持高优先级，避免两个大图同时争抢带宽。
- 首页统一使用系统字体，移除自定义字体声明及预加载，减少约 196 kB 字体下载。
- 关闭 Wrangler 函数名保留，修复 next-themes 内联脚本中的 `__name is not defined`。

| 主入口 JS gzip | 334.13 kB | 125.64 kB（减少 62.4%） |
| 首页 CSS 总量 | 406,738 B | 383,587 B |

以上数据反映构建和资源开销，不能换算成中国不同运营商的实际加载秒数。

## 验证

- 生产构建成功，只预渲染中英文公开首页。
- 首页交互测试：中英文首屏、无 JavaScript 布局、模板预览与 Escape、语言切换、移动端溢出、浅色首页与应用主题恢复。
- 静态路由测试：HTML 与构建产物一致、跨语言 Cookie 不影响文档、HEAD、缓存、尾斜杠、API 不缓存、404、百度验证地址。
- 使用始终返回 599 的探针 Worker，首页和验证文件仍返回 200，应用路径返回 599，确认公开首页不执行 Worker。
- OrcaRouter 的 8 项 Chromium/WebKit 授权与模型列表测试通过。
- 字体的 3 项浏览器测试通过，覆盖进入编辑器和字体未下载完成时编辑。
- Node 自托管通过同一组静态路由测试。
- 全局 TypeScript 检查仍有原有 Next.js 迁移残留和文件系统类型错误；本次修改文件未出现新的类型错误。

使用 Node 22.12 或更新版本：

```sh
pnpm build
pnpm exec wrangler dev --local --port 4311
LANDING_TEST_URL=http://localhost:4311 node --test tests/landing-static.test.mjs tests/landing.browser.mjs
TEST_BASE_URL=http://localhost:4311 node --test tests/orcarouter.browser.mjs
```

字体测试依赖 Vite 的源码模块入口，应对开发服务运行：

```sh
pnpm dev --port 4312
PREVIEW_TEST_URL=http://localhost:4312 node --test tests/fonts.browser.mjs
```

需要更新截图时运行 `pnpm generate:landing-images`，然后提交生成的图片文件。

## 上线后还需观察

本次消除了首页 SSR 的 CPU 开销，并减少浏览器下载和初始化工作。此前发现的 80 次 CPU 超限没有历史请求日志，尚不能确认都来自首页；应在部署后对比 CPU 超限数量及中国地区 `/zh` 的真实用户指标。跨境线路问题仍需国内多地区、三运营商的探测数据判断。
